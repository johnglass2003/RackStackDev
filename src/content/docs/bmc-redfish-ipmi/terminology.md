Terms to define:

- **BMC** (Baseboard Management Controller)
- **iDRAC** (Integrated Dell Remote Access Controller)
- **iLO** (Integrated Lights-Out — HPE)
- **XCC** (XClarity Controller — Lenovo)
- **IPMI** (Intelligent Platform Management Interface)
- **Redfish**
- **DMTF** (Distributed Management Task Force)
- **Out-of-band management**
- **In-band management**
- **SoC** (System on Chip)
- **Standby power**
- **RMCP / RMCP+** (Remote Management Control Protocol)
- **SOL** (Serial-over-LAN)
- **SEL** (System Event Log)
- **FRU** (Field Replaceable Unit)
- **SDR** (Sensor Data Repository)
- **SNMP** (Simple Network Management Protocol)
- **Management network / OOB network**
- **Cipher suite** (in the IPMI security context)
- **RAKP** (Remote Authenticated Key-Exchange Protocol — IPMI auth)
- **@odata.id** (Redfish hypermedia link field)
- **REST** (Representational State Transfer)
- **Session token** (Redfish auth)
